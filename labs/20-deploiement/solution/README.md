# outils

Petits utilitaires dates et réseau, en Python pur (aucune dépendance).

```bash
pip install .
outils ip 10.0.0.1              # 10.0.0.1 : privée
outils jours 2026-09-07 2026-09-13
outils port stranix.net 443
```

Ce paquet est la solution du [labo 20](../README.md) du cours *Python de zéro à FastAPI*.
